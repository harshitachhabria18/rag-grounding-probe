# RAG Grounding Probe

This is a small throwaway repository created to test whether a Retrieval-Augmented 
Generation (RAG) system answers questions using retrieved content, rather than an LLM's 
own training knowledge.

The `quantify_zorbex` function contains entirely fictional logic with no real-world 
meaning. Any AI system correctly answering questions about its exact behavior must be 
retrieving this repo's actual content, since this function and its logic do not exist 
anywhere else.
